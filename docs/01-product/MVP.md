# MVP 范围说明

> MVP 目标：用最少功能完成 API 自动化测试闭环。  
> 判断标准：能管理 API 用例、能执行、能保存结果、能定位失败。

---

## 1. MVP 闭环

```text
登录
  ↓
创建 API 项目
  ↓
配置执行环境
  ↓
创建集合和 API 用例
  ↓
配置变量和断言
  ↓
执行单用例 / 集合 / 项目
  ↓
查看执行报告
```

---

## 2. P0 必须实现

### 2.1 认证与用户角色

- 登录。
- JWT 鉴权。
- Token 刷新。
- 退出登录。
- 当前用户信息。
- 修改密码。
- 用户启用/禁用。
- 简单角色：`admin`、`tester`、`viewer`。

### 2.2 API 项目

- 创建项目。
- 项目列表。
- 项目详情。
- 更新项目。
- 删除项目。

### 2.3 环境

- 创建环境。
- 环境列表。
- 环境详情。
- 更新环境。
- 删除环境。
- 默认环境。
- `base_url`、`headers`、`variables`。

### 2.4 集合

- 创建集合。
- 集合列表。
- 集合详情。
- 更新集合。
- 删除集合。

MVP 只做一层集合，不做树形目录拖拽。

### 2.5 API 用例

- 创建用例。
- 用例列表。
- 用例详情。
- 更新用例。
- 删除用例。
- 启用/禁用用例。
- 请求方法：GET、POST、PUT、PATCH、DELETE。
- 请求体：none、json、form、raw。

### 2.6 变量替换

- 环境变量替换。
- 内置变量：`{{$timestamp}}`、`{{$uuid}}`、`{{$random_int}}`。
- 支持 path、headers、query、body。
- 变量缺失要给出明确错误。

### 2.7 断言引擎

- `status_code`
- `json_path`
- `header`
- `response_time`
- `body_contains`

支持操作符：

- `eq`
- `ne`
- `gt`
- `gte`
- `lt`
- `lte`
- `contains`
- `exists`
- `not_exists`

### 2.8 执行引擎

- 单用例执行。
- 集合执行。
- 项目执行。
- 使用 httpx 发送请求。
- 默认超时 30 秒。
- 保存实际请求、响应、断言结果和错误信息。

### 2.9 报告

- 执行批次列表。
- 执行批次详情。
- 执行结果列表。
- 单条结果详情。
- 统计通过率和耗时。

---

## 3. P1 可延后

- OpenAPI / Swagger 导入。
- 自动生成基础用例。
- 集合/用例复制。
- 有限并发执行。
- 报告导出。
- 趋势统计。
- 前端完整管理页面。

---

## 4. 明确不属于 MVP

- UI 自动化。
- 性能测试。
- 安全测试。
- AI 生成用例。
- AI Agent。
- RAG。
- 定时任务。
- 消息通知。
- 分布式执行。
- Kubernetes / Helm。
- 多租户。
- 用户自定义脚本执行。

---

## 5. MVP 完成判定

- [ ] 登录用户可以创建项目。
- [ ] 项目下可以配置环境。
- [ ] 项目下可以创建集合和 API 用例。
- [ ] 用例可以引用环境变量。
- [ ] 用例可以配置断言。
- [ ] 可以执行单用例。
- [ ] 可以执行集合或项目。
- [ ] 执行结果持久化保存。
- [ ] 报告可以查看请求、响应、断言和失败原因。
- [ ] 核心接口有 pytest API 测试覆盖。
