# PRD：API 自动化测试平台产品需求

> 当前阶段产品定位：只做 **API 自动化测试平台 MVP**。  
> 设计原则：第一性原理识别核心问题，奥姆剃刀原则控制范围，先完成最小可用闭环。

---

## 1. 背景

当前接口测试主要依赖人工在 Postman、Apifox 或脚本中维护和执行，存在以下问题：

- API 用例分散，复用和维护成本高。
- 回归测试依赖人工触发，效率低且容易遗漏。
- 多环境切换容易出错。
- 执行结果分散，历史不可追溯。
- 失败原因定位需要反复查请求、响应和断言。

因此需要一个轻量、稳定、可持续迭代的平台，统一管理 API 测试资产和执行结果。

---

## 2. 产品目标

构建一个 API 自动化测试平台，实现以下最小闭环：

```text
认证登录 → 项目管理 → 环境管理 → API 用例管理 → 执行测试 → 查看报告
```

MVP 成功的关键不是功能多，而是闭环稳定、数据清晰、结果可追溯。

---

## 3. 目标用户

| 用户 | 诉求 | 当前阶段权限 |
|------|------|--------------|
| 管理员 Admin | 管理用户、角色和所有测试资产 | 全部权限 |
| 测试工程师 Tester | 维护 API 用例、执行测试、查看报告 | API 测试核心权限 |
| 查看者 Viewer | 查看项目、用例和报告 | 只读权限 |

---

## 4. 核心问题与解决方案

| 核心问题 | MVP 解决方案 |
|----------|--------------|
| 用例分散 | 用项目、集合、用例统一管理 |
| 环境切换混乱 | 用环境配置管理 Base URL、Headers、Variables |
| 执行不可重复 | 平台统一触发单用例、集合、项目执行 |
| 结果不可追溯 | 保存 TestRun 和 TestResult |
| 失败定位慢 | 报告展示请求、响应、断言和错误信息 |

---

## 5. 功能需求

### 5.1 认证与账号

- 用户登录。
- JWT 鉴权。
- Token 刷新。
- 退出登录。
- 当前用户信息。
- 修改密码。
- 管理员管理用户和角色。

### 5.2 API 项目管理

- 创建项目。
- 查询项目列表和详情。
- 更新项目。
- 删除项目。

项目是 API 测试资产的归属边界。

### 5.3 环境管理

- 每个项目可配置多个环境。
- 环境包含 `base_url`、`headers`、`variables`。
- 支持默认环境。
- 执行时按环境替换变量。

### 5.4 集合与用例管理

- 集合用于分组 API 用例。
- 用例包含请求方法、路径、请求头、查询参数、请求体、断言规则。
- 支持 GET、POST、PUT、PATCH、DELETE。
- 支持用例启用/禁用。

### 5.5 变量替换

支持语法：

```text
{{token}}
{{user_id}}
{{$timestamp}}
{{$uuid}}
{{$random_int}}
```

变量可用于 path、headers、query、body 和断言 expected 值。

### 5.6 断言

MVP 支持规则化断言：

- `status_code`
- `json_path`
- `header`
- `response_time`
- `body_contains`

不支持用户自定义脚本断言，避免安全风险和维护成本。

### 5.7 测试执行

- 单用例执行。
- 集合执行。
- 项目执行。
- 使用指定环境执行。
- 默认超时 30 秒。
- 保存执行批次和每条结果。

### 5.8 测试报告

- 执行概览：总数、通过数、失败数、跳过数、通过率、耗时。
- 结果列表：每条用例状态和耗时。
- 结果详情：实际请求、响应、断言结果、错误信息。
- 历史执行查询。

---

## 6. 非功能需求

| 类别 | 要求 |
|------|------|
| 安全 | 密码哈希、JWT 鉴权、敏感信息不进日志 |
| 可维护 | Router → Service → Repository 分层 |
| 可测试 | 核心逻辑有单元测试，接口有 API 测试 |
| 可追溯 | 执行结果保存请求、响应、断言快照 |
| 简单性 | MVP 不引入消息队列、分布式执行和 AI 能力 |

---

## 7. 当前阶段不做

- UI 自动化测试。
- 性能测试、压力测试、安全测试。
- AI Agent / RAG。
- 定时任务。
- CI/CD 深度集成。
- 分布式执行。
- 多租户。
- 用户自定义脚本执行。
- Allure 静态站点托管。
