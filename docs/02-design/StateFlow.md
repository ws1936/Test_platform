# API 自动化测试平台 · State Flow 状态流

> 版本：v1.0  
> 适用范围：API 自动化测试平台前端所有页面 / 组件 / 浮层状态  
> 配套：`DesignSystem.md`（视觉）、`Wireframe.md`（线框）、`ComponentLibrary.md`（组件契约）  
> 约束边界：**仅规范页面状态的视觉与行为变化，不涉及任何样式 / 业务逻辑**

---

## 0. 文档定位

平台任意页面 / 组件 / 浮层，都处于**有限个状态**之一。本文档为每种状态定义：

| 维度 | 说明 |
|---|---|
| **视觉** | 页面 / 区块的呈现方式 |
| **按钮变化** | 主操作 / 次操作按钮的禁用、Loading、文字变化 |
| **Table 变化** | 表格如何呈现该状态 |
| **用户提示** | Toast / Alert / 文案提示用户 |

共定义 **10 种核心状态**：

| 编号 | 状态 | 性质 |
|---:|---|---|
| 1 | Loading | 异步加载中 |
| 2 | Skeleton | 加载中（占位） |
| 3 | Empty | 数据为空 |
| 4 | 403 | 无权限 |
| 5 | 404 | 资源不存在 |
| 6 | 500 | 服务异常 |
| 7 | Success | 操作成功 |
| 8 | Running | 长任务执行中 |
| 9 | Deleting | 删除操作中 |
| 10 | Submitting | 表单提交中 |

---

## ① 状态分类总览

### 1.1 状态维度

| 维度 | 状态 | 说明 |
|---|---|---|
| **数据维度** | Loading / Skeleton / Empty | 数据是否就绪 |
| **错误维度** | 403 / 404 / 500 | 数据是否可读 |
| **操作维度** | Submitting / Deleting / Running | 用户操作进行中 |
| **结果维度** | Success | 操作完成 |

### 1.2 状态生命周期

```text
                            ┌──────────────┐
                            │   Mounted    │
                            └──────┬───────┘
                                   ↓
                ┌──────────────────────────────────┐
                │                                  │
                ↓                                  ↓
       ┌─────────────────┐               ┌──────────────────┐
       │     Loading     │               │    Skeleton      │
       │   (有缓存时)     │               │   (无缓存时)      │
       └────────┬────────┘               └────────┬─────────┘
                ↓                                  ↓
        ┌───────────────┐         ┌──────────────────────────────────┐
        │               │         │                                  │
        ↓               ↓         ↓                                  ↓
   ┌─────────┐   ┌─────────┐  ┌─────────┐   ┌─────────┐    ┌─────────┐
   │ Success │   │  Error  │  │  Data   │   │  403    │    │  404    │
   │ (首次)  │   │  500    │  │ Ready   │   │         │    │         │
   └─────────┘   └────┬────┘  └────┬────┘   └─────────┘    └─────────┘
                      │            │
                      ↓            ↓
                 ┌──────────┐  ┌─────────────────────┐
                 │  Retry   │  │  Empty / Success    │
                 │ (toLoad) │  │  / Submitting / ... │
                 └──────────┘  └─────────────────────┘
```

### 1.3 状态叠加规则

| 可叠加状态 | 规则 |
|---|---|
| Loading + Empty | ❌ 互斥 |
| Loading + 500 | ✅ 加载中 → 失败后转 500 |
| Submitting + Deleting | ❌ 互斥（同一时刻只能一个） |
| Running + Submitting | ✅ Run 发起时 Submitting，提交完成后转 Running |
| Success + 任意 | ✅ Success 是瞬态，3 秒后消失 |

## ② Loading · 加载中

### 2.1 视觉

| 区块 | 表现 |
|---|---|
| 页面整体 | 内容区域显示 `<Spin size="large">` + 占位块 |
| 卡片 | 卡片内显示 `<Skeleton active>` |
| 表格 | 表格显示骨架行（默认 5 行） |
| 表单 | 字段下方显示骨架条 |
| 按钮 | 主操作按钮变 `loading` 态（不可重复点击） |
| PageHeader | 标题正常显示，副标题变 skeleton |

### 2.2 按钮变化

| 按钮 | 变化 |
|---|---|
| 主操作 | `disabled={true}` + 显示 Loading icon |
| 次操作 | `disabled={true}`（点击不响应） |
| Cancel | **不禁用**（允许用户主动取消） |
| 刷新按钮 | 自动旋转 |

### 2.3 Table 变化

| 列 | 行为 |
|---|---|
| 表头 | 正常显示 |
| 行 | 5~8 行骨架（灰底 + 渐变） |
| 分页器 | 隐藏 |
| 操作列 | 骨架 |
| 选中 / 多选 | 禁用 |

### 2.4 用户提示

| 场景 | 提示 |
|---|---|
| 加载 < 1s | 不显示任何提示（避免闪烁） |
| 加载 1~3s | Spin 旋转，无文案 |
| 加载 3~10s | 附加文案 "数据加载较慢，请稍候" |
| 加载 > 10s | 提示 "加载超时，<a>点击重试</a>"（可点击重试） |

### 2.5 适用页面

所有列表页 / 详情页 / Drawer / Modal 的初次加载。

## ③ Skeleton · 骨架屏

### 3.1 视觉

| 区块 | 表现 |
|---|---|
| 页面 | 整体被骨架占位（白底 + 灰条） |
| 卡片 | 标题占位 + 多行段落占位 |
| 表格 | 6~10 行表格骨架 |
| KPI 卡 | 数字占位 + 进度条占位 |
| PageHeader | 标题占位 |

### 3.2 按钮变化

| 按钮 | 变化 |
|---|---|
| 所有按钮 | `disabled={true}` + 灰色 |
| 主操作 | 不显示 Loading（Skeleton 已是占位） |

### 3.3 Table 变化

| 行 | 行为 |
|---|---|
| 行数 | 6~10 行（与列表实际行数一致为佳） |
| 列宽 | 与真实列宽一致（避免布局抖动） |
| 边框 | 显示 |
| 圆角 | 显示 |

### 3.4 用户提示

- 无文案提示（避免干扰视觉占位）。
- 不显示"加载中"字样（骨架本身就是提示）。

### 3.5 Loading vs Skeleton 选择

| 场景 | 选择 |
|---|---|
| 数据 < 200ms 返回 | 不显示任何占位 |
| 已有缓存 + 增量加载 | Loading（Spin） |
| 首次加载 / 无缓存 | Skeleton（骨架屏） |
| Drawer / Modal 内表单 | Drawer Header 正常，Body 内 Skeleton |
| 路由切换 | 路由级别 Skeleton（不闪 Loading） |

## ④ Empty · 空状态

### 4.1 视觉

| 区块 | 表现 |
|---|---|
| 页面 | 居中显示 EmptyView（图标 + 标题 + 描述 + 下一步动作） |
| 表格 | 表格内显示 emptyText（同 EmptyView，但小一号） |
| 卡片 | 卡片内显示 EmptyView（compact 模式） |
| KPI 卡 | 显示 "—" 占位 |

### 4.2 按钮变化

| 按钮 | 变化 |
|---|---|
| 主操作（创建 / 新建） | **高亮**（吸引用户操作） |
| 刷新 | 正常可用 |
| 操作列 | **不渲染**（无数据可操作） |

### 4.3 Table 变化

| 行 | 行为 |
|---|---|
| 数据行 | 0 行 |
| 空态 | 显示 `locale.emptyText = <EmptyView>` |
| 分页 | 显示 "共 0 条" |
| 操作列 | 不渲染 |

### 4.4 用户提示

| 场景 | 标题 | 描述 | 主操作 |
|---|---|---|---|
| Project 列表空 | "还没有 Project" | "创建第一个 Project，开始 API 测试" | [+ 新建 Project] |
| 环境列表空 | "还没有环境" | "创建你的第一个环境" | [+ 新建环境] |
| Suite 列表空 | "还没有 Suite" | "按业务场景组织你的回归范围" | [+ 新建 Suite] |
| Case 列表空 | "还没有 API Case" | "创建 Case 手动编写，或导入 OpenAPI" | [+ 新建 Case] [导入 OpenAPI] |
| Run 列表空 | "还没有执行记录" | "发起一次 Run 来生成第一份报告" | [⚡ 前往执行中心] |
| 搜索结果空 | "没有匹配结果" | "试试调整搜索关键字或筛选条件" | [清空筛选] |
| 筛选结果空 | "没有符合条件的数据" | "已应用筛选：状态 = 通过" | [清除筛选] |

### 4.5 适用场景

| 数据状态 | Empty 标题 |
|---|---|
| 全空（首次访问） | "还没有 XXX" |
| 搜索后无结果 | "没有匹配结果" |
| 筛选后无结果 | "没有符合条件的数据" |
| 已被删除 | "数据已被删除" |

## ⑤ 403 · 无权限

### 5.1 视觉

| 区块 | 表现 |
|---|---|
| 页面 | 全屏 `<Result status="403">` |
| 图标 | 🔒 锁形 |
| 标题 | "无权访问" |
| 描述 | "你当前账号无权访问该资源" |
| PageHeader | 不显示 |
| Toolbar | 不显示 |
| Sidebar | 高亮当前模块，但内容区显示错误页 |

### 5.2 按钮变化

| 按钮 | 文案 | 行为 |
|---|---|---|
| 主操作 | "返回 Dashboard" | 跳 `/dashboard` |
| 次操作 | "申请权限" | **仅文案按钮**，点击 Toast "请联系管理员" |

### 5.3 Table 变化

| 区块 | 行为 |
|---|---|
| Table | **不渲染**（页面被错误页完全替代） |
| Sidebar | 保留（用户可手动切到其他有权限模块） |

### 5.4 用户提示

| 渠道 | 内容 |
|---|---|
| 页面 | "你当前账号无权访问该资源" |
| Toast | "无权访问"（顶部短暂提示） |
| Console | 后端 error message |

### 5.5 触发场景

| 场景 | 触发 |
|---|---|
| 访问其他用户的 Project | 后端返回 403 |
| 访问系统管理页（普通用户） | 前端 RouteGuard 拦截 |
| 操作受保护资源 | 后端返回 403 |
| Token 过期 + Refresh 失败 | 跳登录（**不算 403**，见 13.4） |

### 5.6 与 Empty / 404 的区别

| 状态 | 区别 |
|---|---|
| Empty | 数据合法但为空 |
| 403 | 数据存在但无权访问 |
| 404 | 资源不存在 |

## ⑥ 404 · 资源不存在

### 6.1 视觉

| 区块 | 表现 |
|---|---|
| 页面 | 全屏 `<Result status="404">` |
| 图标 | ❓ / 📂 文件 |
| 标题 | "资源不存在" |
| 描述 | "该资源可能已被删除，或当前 Project 中没有此对象" |
| PageHeader | 不显示 |
| Toolbar | 不显示 |

### 6.2 按钮变化

| 按钮 | 文案 | 行为 |
|---|---|---|
| 主操作 | "返回上级" | 跳上一级路由（`history.back()`） |
| 次操作 | "返回项目列表" | 跳 `/projects` |

### 6.3 Table 变化

| 区块 | 行为 |
|---|---|
| Table | **不渲染** |
| Sidebar | 保留 |

### 6.4 用户提示

| 渠道 | 内容 |
|---|---|
| 页面 | "该资源可能已被删除，或当前 Project 中没有此对象" |
| Toast | （可选）"资源不存在" |

### 6.5 触发场景

| 场景 | 触发 |
|---|---|
| 手动输错 URL | 路由不存在 |
| 资源被另一个用户删除 | 后端 404 |
| 跨 Project 访问 | 见 NavigationUX §8.2 切换策略 |
| 历史链接失效 | 后端 404 |

### 6.6 上下文保留

进入 404 页时，**保留**：

- 用户登录态
- 当前 Project（如果是从 Project 内进入）
- Sidebar 高亮位置

进入 404 页时，**不保留**：

- 失效的对象 ID（URL 中的 `?runId=` 等）

## ⑦ 500 · 服务异常

### 7.1 视觉

| 区块 | 表现 |
|---|---|
| 页面 | 全屏 `<Result status="error">` 或局部 `<ErrorView>` |
| 图标 | ⚠ 警示 |
| 标题 | "加载失败" / "服务异常" |
| 描述 | **后端 error message**（不允许固定文案"出错了"） |
| PageHeader | 正常显示 |

### 7.2 按钮变化

| 按钮 | 文案 | 行为 |
|---|---|---|
| 主操作 | "重新加载" | 重新发起请求 |
| 次操作 | "返回 Dashboard" | 跳 Dashboard |

### 7.3 Table 变化

| 场景 | 表现 |
|---|---|
| 整页加载失败 | Table 区域显示 ErrorView（占满） |
| 行内某条失败 | 该行显示 `<Alert type="error">` + 重试按钮 |
| 局部加载失败 | 显示 `<Empty image="error">` + 重试 |

### 7.4 用户提示

| 渠道 | 内容 |
|---|---|
| 页面 | "网络异常，请检查后重试" + 后端 message |
| Toast | "加载失败"（若是非关键加载） |
| Console | 完整错误堆栈 |

### 7.5 触发场景

| 场景 | HTTP | 提示 |
|---|---|---|
| 网络断开 | — | "网络连接失败，请检查网络" |
| 后端 500 | 500 | 后端 message（如 "Internal Server Error"） |
| 后端 503 | 503 | "服务暂不可用，请稍后再试" |
| 请求超时 | 504 | "请求超时，请稍后再试" |
| 业务异常 | 400 | 后端 message（如 "环境不存在"） |

### 7.6 自动重试策略

| 错误 | 重试策略 |
|---|---|
| 网络断开 | ❌ 不自动重试，由用户手动 |
| 500 / 503 | ❌ 不自动重试 |
| 超时 | ✅ 1 次自动重试（指数退避） |
| 幂等操作 GET | 可配置自动重试 |

## ⑧ Success · 操作成功

### 8.1 视觉

| 区块 | 表现 |
|---|---|
| 页面 | 短暂 Toast 提示（默认 3 秒自动消失） |
| 列表 | 数据自动更新（不需手动刷新） |
| Drawer / Modal | 自动关闭 |
| 表单 | 自动重置 + 跳转 |

### 8.2 按钮变化

| 按钮 | 变化 |
|---|---|
| 主操作 | 立即恢复 `disabled={false}` |
| Loading 状态 | 立即清除 |
| 计数器 | 重置回 0 |

### 8.3 Table 变化

| 操作 | Table 表现 |
|---|---|
| 新建 | 新行插入到列表顶部（按更新时间排序） |
| 编辑 | 对应行内容更新（无需刷新整表） |
| 删除 | 对应行从列表中移除 |
| 批量删除 | 选中行批量移除 |
| 启用 / 禁用 | 对应行的 Switch 状态更新 |

### 8.4 用户提示

| 操作 | Toast |
|---|---|
| 新建成功 | "创建成功" |
| 编辑成功 | "保存成功" |
| 删除成功 | "删除成功" |
| 执行成功 | "执行完成，正在打开报告" |
| 复制成功 | "已复制到剪贴板" |
| 导入成功 | "导入成功：新增 N，跳过 M，覆盖 K" |
| 设置默认 | "已设为默认环境" |

### 8.5 Toast 类型

| 场景 | 类型 | 时长 |
|---|---|---|
| 成功 | `message.success` | 3 秒 |
| 信息 | `message.info` | 3 秒 |
| 警告 | `message.warning` | 4 秒 |
| 错误 | `message.error` | 5 秒 |
| Loading | `message.loading` | 不自动消失 |

### 8.6 Success 后的跳转

| 操作 | 跳转策略 |
|---|---|
| 新建 Project | 跳新 Project 概览 |
| 新建 Suite | 留在 Suite 列表，Toast |
| 新建 Case | 留在 Suite 详情或 Case 列表 |
| 编辑 Case | 跳回原 Suite 详情（`?from=`） |
| Run 提交成功 | 跳 Run 报告详情 |
| Run 完成 | 跳 Run 报告详情 |
| 删除最后一项 | 留在列表（显示 EmptyView） |

## ⑨ Running · 长任务执行中

### 9.1 视觉

| 区块 | 表现 |
|---|---|
| Drawer Body | 显示 Spin + "正在同步执行…" + 进度文案 |
| 主操作按钮 | 变 Loading，文字变为 "正在同步执行…" |
| Drawer 关闭 | 禁用（不可关闭） |
| PageHeader | 主操作按钮 disabled + Loading |
| 全屏遮罩 | 不启用（避免阻挡其他操作） |

### 9.2 按钮变化

| 按钮 | 变化 |
|---|---|
| Run Now | `loading={true}` + `disabled={true}` + 文字 "正在同步执行…" |
| Cancel | `disabled={true}` + 文字 "执行中…"（不可取消） |
| Drawer 关闭 [×] | 隐藏 / 禁用 |
| `maskClosable` | `false` |
| 路由切换 | 弹 Popconfirm "当前 Run 正在执行，确定离开？" |

### 9.3 Table 变化

| 列 | 变化 |
|---|---|
| Run 状态 | 显示 `[执行中]` Tag（蓝色 processing） |
| 通过率 | "—" 占位 |
| 耗时 | 实时累加（如 "0:05 → 0:06 → 0:07"） |
| 操作列 | "查看" 链接可用，"再次执行" 禁用 |

### 9.4 用户提示

| 渠道 | 内容 |
|---|---|
| Drawer 内 | "后端为同步执行；请勿关闭或重复提交。" |
| Toast（提交开始） | "执行中…" |
| Toast（完成） | "执行完成，正在打开报告" |
| Alert（提交失败） | "执行失败：[后端 message]" |

### 9.5 同步 vs 异步

当前 Run 为**同步执行**（前端阻塞等待后端响应），因此：

- 无进度条（无百分比）
- 无任务队列
- 无取消按钮
- 等待时间取决于 Case 数量（通常 1~60 秒）

### 9.6 超时处理

| 等待时间 | 行为 |
|---|---|
| < 60 秒 | 正常等待 |
| 60~120 秒 | 提示 "执行耗时较长，请耐心等待" |
| > 120 秒 | 提示 "执行超时，可能是网络问题，<a>检查连接</a>" |
| 后端超时（> 5 分钟） | 跳错误页，提示 "Run 超时，请稍后在报告中查看结果" |

## ⑩ Deleting · 删除操作中

### 10.1 视觉

| 区块 | 表现 |
|---|---|
| 按钮（Popconfirm） | 二次确认弹窗出现 |
| 删除按钮 | `loading={true}` + `disabled={true}` |
| 行 | 行变浅红色，文字变灰（即将删除） |
| Table | 不可选中其它行 |
| 计数 | 删除计数 +1 |

### 10.2 按钮变化

| 按钮 | 变化 |
|---|---|
| 触发删除 | 弹出 Popconfirm / Modal |
| Popconfirm "确认删除" | `loading={true}` + 文字 "删除中…" |
| Popconfirm "取消" | 禁用 Loading 期间点击 |
| 其它行操作 | 禁用 |

### 10.3 Table 变化

| 场景 | Table 表现 |
|---|---|
| 单行删除中 | 该行显示 Loading 遮罩 + 删除中文字 |
| 批量删除中 | 选中行高亮为浅红色 + 进度提示 "正在删除 N 个" |
| 删除失败 | 该行恢复 + Alert 错误 |
| 删除成功 | 该行从列表中消失（带淡出动画） |

### 10.4 用户提示

| 渠道 | 内容 |
|---|---|
| Popconfirm | "确认删除 XXX？" + 详细说明（如引用关系） |
| Modal（高危） | "请输入 XXX 名称以确认删除" |
| Toast（成功） | "删除成功" |
| Toast（失败） | "删除失败：[后端 message]" |

## ⑫ 状态叠加规则（复合态）

### 12.1 Loading + Empty（互斥）

不能同时存在：数据要么在加载、要么为空。

### 12.2 Loading + Error

加载中 → 失败后转为 Error（500），可点击 Retry 回到 Loading。

### 12.3 Running + Loading

Run 执行期间（同步），整个页面仍可显示其它区块的 Loading（如"最近 Run"列表更新）。

### 12.4 Submitting + Running

Submitting 是发起阶段（毫秒级），Running 是执行阶段（秒级）。通常 Submitting 结束后立即进入 Running，或直接进入 Success / Error。

### 12.5 Success + 任意

Success 是瞬态（Toast 3 秒），可与任何其它状态叠加。

### 12.6 状态优先级

| 优先级 | 状态 | 说明 |
|---:|---|---|
| 1 | 403 | 完全替代页面 |
| 2 | 404 | 完全替代页面 |
| 3 | ErrorBoundary | 替代整个 React 树 |
| 4 | 500 | 替代当前区块 |
| 5 | Loading / Skeleton | 占位 |
| 6 | Empty | 数据为空 |
| 7 | Data Ready | 正常显示 |

## ⑯ 状态切换的"软"提示

### 16.1 Toast vs Alert 选择

| 场景 | 选择 |
|---|---|
| 一次性提示 | Toast（3 秒消失） |
| 用户必须看到 | Alert（持续直到关闭） |
| 阻塞性错误 | Modal（如"会话过期，请重新登录"） |
| 表格行内错误 | Alert + 重试按钮 |

### 16.2 Alert vs Result 选择

| 场景 | 选择 |
|---|---|
| 区块级错误 | Alert（如 Drawer 内某个字段加载失败） |
| 整页错误 | Result（如 403 / 404 / 500 全屏） |
| 表单字段错误 | Field-level 错误（红字） |

### 16.3 Loading 时长阈值

| 时长 | 行为 |
|---|---|
| < 200ms | 不显示 Loading（避免闪烁） |
| 200~1000ms | Spin |
| 1~3s | Spin + 占位文案 |
| 3~10s | Spin + "加载较慢" |
| > 10s | Loading + 重试按钮 |

## ⑰ 边界情况

### 17.1 网络断开

| 场景 | 表现 |
|---|---|
| 全局断开 | 全屏 ErrorView "网络连接失败" |
| 单请求断开 | 行内 Alert + 重试按钮 |
| 提交中断 | 表单恢复可编辑 + Toast |

### 17.2 Token 过期

| 阶段 | 行为 |
|---|---|
| 请求时 | 先尝试 Refresh Token |
| Refresh 成功 | 静默重发原请求 |
| Refresh 失败 | Toast "登录已过期" → 跳登录 |
| 登录成功 | 跳回原 URL（`sessionStorage.returnTo`） |

### 17.3 并发操作

| 场景 | 处理 |
|---|---|
| 同一按钮连续点击 | 第二次点击被禁用（Loading） |
| 两个不同按钮同时操作 | 互不影响，各自状态独立 |
| 多个 Tab 同时在线 | 不支持单点登出 |

### 17.4 慢网络

| 时长 | 行为 |
|---|---|
| > 5s | Loading 显示 "数据加载较慢" |
| > 30s | Loading 显示 "请检查网络" + 重试 |
| > 60s | 自动 Cancel，显示错误 |

### 17.5 离线

当前不支持 PWA / 离线访问，离线时所有请求失败，提示 "网络连接失败"。

## ⑱ 无障碍 / 键盘

### 18.1 Loading

- Spin 必须有 `aria-label="加载中"`。
- Skeleton 区块有 `role="status" aria-live="polite"`。

### 18.2 Empty / Error

- EmptyView / ErrorView 标题使用 `<h2>` 语义化标签。
- 图标必须有 `aria-hidden="true"`（屏幕阅读器跳过）。

### 18.3 Toast

- Toast 自动朗读（默认）。
- 时长 ≤ 5 秒（避免长时间朗读干扰）。
- 错误 Toast 必须可关闭。

### 18.4 键盘可达

- 所有按钮 `Tab` 可达。
- Submitting 期间 `Tab` 顺序不变，但禁用按钮不能 focus。
- Esc 关闭顶层 Drawer / Modal（不在 Submitting 时）。
