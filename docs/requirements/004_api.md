# API测试模块需求文档

## 1. 功能概述

### 1.1 模块名称
API测试管理模块

### 1.2 功能描述
提供API接口测试用例的管理、执行和报告功能。

## 2. 用户故事

### US-201 创建API测试用例
**作为** 测试员
**我希望** 能够创建API测试用例
**以便** 对接口进行自动化测试

**验收标准：**
- 支持GET/POST/PUT/DELETE等HTTP方法
- 支持设置请求头、请求参数、请求体
- 支持设置断言规则
- 支持环境变量引用

### US-202 组织测试用例
**作为** 测试员
**我希望** 能够按模块组织测试用例
**以便** 更好地管理和维护

**验收标准：**
- 支持创建测试集合（Collection）
- 支持目录结构组织
- 支持用例排序和拖拽

### US-203 执行测试
**作为** 测试员
**我希望** 能够执行测试用例
**以便** 验证接口功能

**验收标准：**
- 支持单个用例执行
- 支持批量执行
- 支持定时执行
- 实时显示执行进度

### US-204 查看测试报告
**作为** 测试员
**我希望** 能够查看详细的测试报告
**以便** 分析测试结果

**验收标准：**
- 显示请求/响应详情
- 显示断言结果
- 显示执行时间
- 支持历史对比

## 4. 接口设计

### 4.1 项目管理
```
POST   /api/v1/projects          # 创建项目
GET    /api/v1/projects          # 获取项目列表
GET    /api/v1/projects/{id}     # 获取项目详情
PUT    /api/v1/projects/{id}     # 更新项目
DELETE /api/v1/projects/{id}     # 删除项目
```

### 4.2 集合管理
```
POST   /api/v1/projects/{project_id}/collections          # 创建集合
GET    /api/v1/projects/{project_id}/collections          # 获取集合列表
PUT    /api/v1/collections/{id}                            # 更新集合
DELETE /api/v1/collections/{id}                            # 删除集合
```

### 4.3 用例管理
```
POST   /api/v1/collections/{collection_id}/cases          # 创建用例
GET    /api/v1/collections/{collection_id}/cases          # 获取用例列表
GET    /api/v1/cases/{id}                                  # 获取用例详情
PUT    /api/v1/cases/{id}                                  # 更新用例
DELETE /api/v1/cases/{id}                                  # 删除用例
```

### 4.4 测试执行
```
POST   /api/v1/projects/{project_id}/runs                 # 创建执行
GET    /api/v1/projects/{project_id}/runs                 # 获取执行列表
GET    /api/v1/runs/{id}                                   # 获取执行详情
GET    /api/v1/runs/{id}/results                          # 获取执行结果
```

### 4.5 断言规则
```json
{
  "assertions": [
    {
      "type": "status_code",
      "expected": 200,
      "operator": "eq"
    },
    {
      "type": "json_path",
      "path": "$.data.id",
      "expected": "not_null",
      "operator": "exists"
    },
    {
      "type": "response_time",
      "expected": 1000,
      "operator": "lt"
    },
    {
      "type": "header",
      "key": "Content-Type",
      "expected": "application/json",
      "operator": "contains"
    }
  ]
}
```

## 5. 环境变量

### 5.1 变量类型
- 项目级变量：项目内所有用例共享
- 集合级变量：集合内用例共享
- 用例级变量：仅当前用例使用

### 5.2 变量引用语法
```
{{variable_name}}        # 普通变量引用
{{$timestamp}}           # 内置时间戳
{{$random_int}}          # 内置随机数
{{$uuid}}                # 内置UUID
```
